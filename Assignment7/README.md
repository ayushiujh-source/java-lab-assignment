# Assignment 7: Counting Steps and Complexity

## 1. Experiment Title
Counting Steps and Complexity

## 2. Aim
Count the steps a program takes, and write its time complexity as a comment.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- IntelliJ IDEA (IDE shown in the supplied Assignment 1 – Question 1 reference screenshot)
- Git and GitHub

## 4. Theory
Count the steps a program takes, and write its time complexity as a comment. Each question is an independent Java program using the Main class and main method.

## 5. Algorithm / Procedure
### Question 1
**Count one loop**
1. Count each iteration. A single loop has O(n) time complexity.

### Question 2
**Count nested loops**
1. Count each execution of the inner loop body. Nested loops have O(n^2) complexity.

### Question 3
**Count halving steps**
1. Repeatedly halve n until it becomes one and count the divisions.
