# Assignment 15: StringBuilder Methods

## 1. Experiment Title
StringBuilder Methods

## 2. Aim
Build and change text with StringBuilder, using append, insert and deleteCharAt.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- IntelliJ IDEA (IDE shown in the supplied Assignment 1 – Question 1 reference screenshot)
- Git and GitHub

## 4. Theory
Build and change text with StringBuilder, using append, insert and deleteCharAt. Each question is an independent Java program using the Main class and main method.

## 5. Algorithm / Procedure
### Question 1
**Append World to Hello**
1. Create a StringBuilder with Hello, append World with its leading space, then print text and length.

### Question 2
**Append numbers and remove final comma**
1. Append numbers one through five with commas, then remove the last comma.

### Question 3
**Insert Hello before Java**
1. Insert Hello and a space at index zero of a StringBuilder containing Java.
