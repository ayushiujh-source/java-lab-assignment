# Assignment 13: Strings: Methods and Palindromes

## 1. Experiment Title
Strings: Methods and Palindromes

## 2. Aim
Use common String methods, reverse a word, check a palindrome and print substrings.

## 3. Software / Tools Required

## 4. Theory
Use common String methods, reverse a word, check a palindrome and print substrings. Each question is an independent Java program using the Main class and main method.

## 5. Algorithm / Procedure
### Question 1
**String length position and uppercase**
1. Use length(), indexOf('g') and toUpperCase() on Programming.

### Question 2
**Reverse Java using charAt**
1. Visit characters from the final index to zero and append each to a new String.

### Question 3
**Check racecar palindrome**
1. Reverse the word and compare it with the original using equals().

### Question 4
**Print every substring of abc**
1. Use nested loops to print each starting letter's substrings from shortest to longest.
