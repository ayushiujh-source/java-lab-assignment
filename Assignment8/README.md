# Assignment 8: Matrices: Transpose and Row Sums

## 1. Experiment Title
Matrices: Transpose and Row Sums

## 2. Aim
Create two-dimensional arrays, visit them row by row, and build a new matrix from one.

## 4. Theory
Create two-dimensional arrays, visit them row by row, and build a new matrix from one. Each question is an independent Java program using the Main class and main method.

## 5. Algorithm / Procedure
### Question 1
**Fill and print 3 by 4 matrix**
1. Fill the matrix row by row with nested loops and print each row.

### Question 2
**Transpose 3 by 3 matrix**
1. Copy each element to the transposed position by swapping row and column indices.

### Question 3
**Sum each matrix row**
1. Add the three elements in each row and print its total.
