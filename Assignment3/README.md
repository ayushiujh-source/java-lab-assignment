# Assignment 3: Star and Number Patterns

## 1. Experiment Title
Star and Number Patterns

## 2. Aim
Use a loop inside another loop to print stars and numbers in rows.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- IntelliJ IDEA (IDE shown in the supplied Assignment 1 – Question 1 reference screenshot)
- Git and GitHub

## 4. Theory
Use a loop inside another loop to print stars and numbers in rows. Each question is an independent Java program using the Main class and main method.

## 5. Algorithm / Procedure
### Question 1
**4 by 4 star square**
1. Use an outer loop for rows and an inner loop for four stars per row.

### Question 2
**Right triangle of stars**
1. Print i stars on row i using nested loops.

### Question 3
**Number triangle**
1. Print numbers from one through the current row number.

### Question 4
**Upside-down star triangle**
1. Start with four stars and decrease the row length by one each time.
