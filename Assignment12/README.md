# Assignment 12: Insertion Sort

## 1. Experiment Title
Insertion Sort

## 2. Aim
Sort small arrays with insertion sort and count how many values are shifted.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- IntelliJ IDEA (IDE shown in the supplied Assignment 1 – Question 1 reference screenshot)
- Git and GitHub

## 4. Theory
Sort small arrays with insertion sort and count how many values are shifted. Each question is an independent Java program using the Main class and main method.

## 5. Algorithm / Procedure
### Question 1
**Insertion sort array 7 3 5 1**
1. Take each element as key, shift larger values right, then insert the key.

### Question 2
**Insertion sort array 14 3 9 21 6**
1. Take each element as key, shift larger values right, then insert the key.

### Question 3
**Count insertion sort shifts**
1. Count each time an existing value moves one position to the right.
