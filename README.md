## Requirements

- JDK 21 or later
- A Java IDE or a text editor with terminal access
- Git and GitHub

## Run a Program

Open a question folder in the terminal and run:

```bash
javac Main.java
java Main
```

Each question is independent and uses the class name `Main`.

## Validation

A GitHub Actions workflow compiles and runs every `Main.java` program when Java source files are pushed.

## Note About Output Images

The `output.png` files are visual program-output panels included as assignment evidence. They are not raw screenshots of a live IDE session. Run the Java programs locally to confirm their output in your environment.
