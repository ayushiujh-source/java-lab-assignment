## 1. Experiment Title
Arrays: Reverse and Duplicates

## 2. Aim

## 4. Theory
Print an array in reverse order, find the smallest value, and check an array for repeated values. Each question is an independent Java program using the Main class and main method.

## 5. Algorithm / Procedure
### Question 1
**Print array in reverse**
1. Start at the final index and move backwards to zero.

### Question 2
**Find smallest value and index**
1. Initialize the minimum with the first value and update its value and index.

### Question 3
**Find repeated value**
1. Compare each element with later elements using nested loops.
