# Assignment 10: Switch and ArrayList

## 1. Experiment Title
Switch and ArrayList

## 2. Aim
Choose a branch with a switch statement, and store and change a list of numbers in an ArrayList.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- IntelliJ IDEA (IDE shown in the supplied Assignment 1 – Question 1 reference screenshot)
- Git and GitHub

## 4. Theory
Choose a branch with a switch statement, and store and change a list of numbers in an ArrayList. Each question is an independent Java program using the Main class and main method.

## 5. Algorithm / Procedure
### Question 1
**Switch day name**
1. Use switch cases for days one to three and a default case.

### Question 2
**Create ArrayList and read size and index 2**
1. Add four integers, then print the list, its size and the item at index two.

### Question 3
**Update and remove ArrayList items**
1. Use set to update index one and remove to delete index three.
