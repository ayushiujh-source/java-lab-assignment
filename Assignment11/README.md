# Assignment 11: Bubble Sort and Selection Sort

## 1. Experiment Title
Bubble Sort and Selection Sort

## 2. Aim
Sort small arrays with bubble sort and selection sort, and count the swaps.

## 3. Software / Tools Required
- Java Development Kit (JDK)
- IntelliJ IDEA (IDE shown in the supplied Assignment 1 – Question 1 reference screenshot)
- Git and GitHub

## 4. Theory
Sort small arrays with bubble sort and selection sort, and count the swaps. Each question is an independent Java program using the Main class and main method.

## 5. Algorithm / Procedure
### Question 1
**Bubble sort array**
1. Compare adjacent elements and swap out-of-order pairs.

### Question 2
**Selection sort array**
1. Find the smallest remaining element and swap it into the current position.

### Question 3
**Count bubble sort swaps**
1. Increment the swap counter whenever two adjacent values exchange places.
